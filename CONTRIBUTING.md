# Mitarbeit

Inhalte lassen sich über den separat geteilten Bearbeitungslink direkt im Browser ändern. Für Codeänderungen dieses Repository forken, einen Branch erstellen und einen Pull Request öffnen. `npm ci`, `npm test` und `npm run build` müssen erfolgreich sein.

Quellen und Bildlizenzen erhalten. Neue Text- und Medienfelder erhalten stabile, eindeutige IDs. Private Reflexionen und Quizantworten dürfen nicht in den gemeinsamen Redaktionsstand gelangen. Keine Zugangsschlüssel committen. Für Backendänderungen ausschliesslich `gefallene-koenigin-medien` und den zugehörigen Worker verwenden.
